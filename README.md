# 圆柱一键打洞 (CylHolePuncher) — SketchUp 插件

专为圆柱、管线及各类实体模型设计的快速打洞插件，兼容 SketchUp 2025（及 SketchUp 2017+）。

## 安装方法

1. 打开 SketchUp，点击顶部菜单 **扩展程序 (Extensions) → 扩展程序管理器 (Extension Manager)**。
2. 点击左下角红色按钮 **安装扩展程序 (Install Extension)**。
3. 选择本目录下的 `dist/cyl_hole_puncher.rbz`，点击确定即可完成安装（无需重启 SketchUp）。

## 三大功能

安装后会出现在顶部菜单 **扩展程序 → 圆柱一键打洞**、**右键快捷菜单**（选中群组时），以及 **圆柱一键打洞** 独立工具栏：

1. **圆柱侧面批量打洞**
   - 选中圆柱（若未打组可一键自动打组），弹窗直接显示当前圆柱的外径和高度。
   - 设置**孔径、打洞数量（一圈均匀分布）、孔中心离底部高度、深度方式、起始角度、圆孔分段数、圆孔/方孔**，一键打通。
   - 深度方式支持：
     - `径向向心打穿(推荐)`：从圆心向外穿出外壁，空心管/实心柱均可精准得到一圈 N 个孔。
     - `整根前后贯穿`：每根钻头完全贯穿整个圆柱。
     - `外侧向内定深盲孔`：从外壁向内钻指定深度。
2. **圆柱底面/顶面打洞**
   - 在圆柱底面向上或顶面向下垂直打孔（支持正中心单孔，或按分布圆半径均匀打一圈多个孔）。
3. **鼠标点哪打哪（交互打洞工具）**
   - 鼠标移到任意圆柱曲面或平面上，实时显示红色孔位预览圈，左键单击即可沿表面法线垂直打洞。
   - 在右下角数值框直接输入数字（如 `20` 改孔径，或 `20,50` 同时改孔径与孔深），右键菜单可快速切换圆孔/方孔和贯穿模式。

## 特性亮点

- **自动防小尺寸破面**：孔径小于 80mm 时自动内部放大 100 倍做布尔运算再缩回，避免 SketchUp 经典的微小面丢失问题。
- **非实体自动兼容**：目标为闭合实体群组时优先使用原生实体布尔减法（保留闭合实体属性与孔壁厚度）；若目标是非闭合曲面壳体，自动降级为【模型交错】在表面挖洞。
- **支持 `Ctrl+Z` 一步撤回**。
